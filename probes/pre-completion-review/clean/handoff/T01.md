- [ ] 일반 사용자가 `/admin/users` 호출 시 403을 반환한다 (검증: `node --test`의 `blocks viewer on /admin/users with 403`, 모의 환경)
- [ ] 로그인하지 않은 요청은 계속 401을 반환한다 (검증: `node --test`의 `rejects anonymous request with 401`)
- [ ] 컨테이너 이미지 보안 스캔 결과에 미해결 CRITICAL 취약점이 없거나, 있으면 잔여 위험으로 보고한다 (검증: `handoff/T01/evidence/scan-summary.txt`)
