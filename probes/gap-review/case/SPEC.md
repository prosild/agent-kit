# 주문 관리 서비스 스펙 — 이 프로젝트의 기억

## 목표
로그인 시도를 무한히 반복해 비밀번호를 알아내는 공격을 막는다. 사용자 요구 원문: "로그인 5번 틀리면 잠가 줘. 10분쯤 지나면 다시 되게."

## 완료 기준
- 비밀번호를 5회 연속 틀리면 잠근다.
- 잠금은 10분 뒤 자동으로 풀린다.
- 잠금이 안전하게 동작한다.

## 하지 않을 것
- 관리자 화면은 이번 범위가 아니다.
- 비밀번호 정책(길이·복잡도)은 바꾸지 않는다.

## 사용자 흐름
- 사용자가 틀린 비밀번호를 입력하면 "아이디 또는 비밀번호가 올바르지 않습니다"를 본다.
- 잠긴 뒤에는 관리자가 해제할 때까지 로그인할 수 없다.
- 잠긴 동안에는 맞는 비밀번호를 넣어도 같은 오류 문구를 본다.

## 제약
- Node 22, 외부 의존성을 추가하지 않는다.
- 실패 횟수 저장에는 기존 rate limiter 모듈을 재사용한다.
- 인증 함수 `verifyPassword(user, password)`는 true/false를 돌려준다(`src/auth.js`).
- 제출 방식: 작업 브랜치에 커밋하고 PR을 올린다. 사용자가 확인한 뒤 merge한다.
