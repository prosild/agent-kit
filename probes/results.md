- Codex 규칙(`~/.codex/rules/default.rules`)에 init.ps1·verify.ps1 접두사 허용을 넣은 뒤: init 2회·`-Prepare`·`-Accept`·`-CheckAccepted`·`hc ls`·`hc send`·`hc wait`는 승인 창 없이 실행됐다. 설계자는 git을 `-c safe.directory=…`로 직접 불러 소유권 오류 없이 읽었고, 수락 때 변경은 verify 실행 폴더로 봤다.
- 승인 창 2개는 모두 작업자 `hc run`이다. 따옴표 인자가 든 `hc run … "Read …"`는 `hc` 허용 규칙이 있어도 샌드박스 안에서 먼저 실패(파이프 접근 거부)한 뒤 승인을 물었다(뒤 조사에서 원인은 따옴표가 아니라 맨 `--`로 확인. `'--'`로 바꿈, RUNBOOK 3절). 1개는 다른 프로젝트의 살아 있는 터미널이 `task-t01` 이름을 쓰고 있어 생긴 재실행이다.
